

# Fractal Geometry with Iterated Function Systems (IFS)

Python implementations of classic fractals generated by an **Iterated Function System**. Every script implements the two standard IFS algorithms and plots them side by side:

1. **Deterministic algorithm** (set iteration)
2. **Random algorithm** (chaos game)

## Background

An IFS is a finite set of contractive affine maps

```
w_i(x, y) = (a·x + b·y + e,  c·x + d·y + f)
```

each with an associated probability `p_i` (the probabilities sum to 1). The fractal is the unique **attractor** `A` of the system, satisfying

```
A = w_1(A) ∪ w_2(A) ∪ ... ∪ w_k(A)
```

### Algorithm 1: Deterministic (set iteration)

Start with any set `A_0` (here a single point) and repeatedly apply every map to the whole set:

```
A_{n+1} = w_1(A_n) ∪ w_2(A_n) ∪ ... ∪ w_k(A_n)
```

The sequence converges to the attractor. The number of points grows as `k^n`, and the probabilities are not used.

### Algorithm 2: Random (chaos game)

Start at any point. At each step pick a map `w_i` with probability `p_i` and apply it to the current point. The first few points are discarded, and the rest fill out the attractor. It uses constant memory and only needs one point at a time.

## Requirements

- Python 3.8+
- `numpy`
- `matplotlib`

```bash
pip install numpy matplotlib
```

## Usage

Run any script directly. It opens a window showing the deterministic result on the left and the chaos-game result on the right.

```bash
python sierpinski_ifs.py
python square_ifs.py
python fern_ifs.py
python tree_ifs.py
```

## Parameters

Change these in the `__main__` block at the bottom of each script:

| Parameter | Function | Meaning |
|-----------|----------|---------|
| `iterations` | `deterministic_ifs` | Number of set iterations (points = k^iterations). Keep it around 8 to 10. |
| `n_points` | `random_ifs` | Number of chaos-game points to plot |
| `discard` | `random_ifs` | Initial transient points to skip (default 20) |
| `seed` | `random_ifs` | Random seed for reproducible pictures |

## Notes

- Fern: `w1` collapses the plane onto a line segment, which gives the fern's stem.
- The chaos game needs the probabilities to be reasonable. For the fern, the standard weights (0.01, 0.85, 0.07, 0.07) make the frond fill in evenly.
- Both algorithms converge to the same attractor. The deterministic one is easier to reason about, and the random one is cheaper for large point counts.
